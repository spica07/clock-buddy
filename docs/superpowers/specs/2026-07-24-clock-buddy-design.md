# clock-buddy 설계 문서

날짜: 2026-07-24

## 목적
아이에게 시간 읽는 법을 가르치기 위한 아날로그·디지털 시계 동기화 학습 웹앱(PWA). 실시간으로 두 시계가 같이 움직이는 걸 보여주고, 아이가 직접 바늘을 돌려보며 시간 개념을 익히도록 한다.

## 범위
- 독립 정적 웹앱(PWA), 빌드 도구 없음, 순수 HTML/CSS/JS
- 학습 수준: 1분 단위 + 오전/오후 12시간제
- 점수/기록 저장 없음 (매번 단순하게 맞추고 끝)
- 국기 이모지 등 미사용, 밝고 상큼한 키즈 스타일

## 폴더 구조
```
clock-buddy/
├── index.html
├── manifest.json
├── sw.js
├── assets/
│   ├── css/style.css
│   ├── js/clock.js
│   ├── js/quiz.js
│   └── js/app.js
└── icons/
```

## 모드 구조
```
상단 탭: [실시간 보기] [연습하기]
연습하기 하위 탭: [자유롭게 놀기] [문제 풀기]
```

- **실시간 보기**: `setInterval`로 매초 시스템 시각을 읽어 아날로그(시침·분침·초침)와 디지털 표시를 함께 갱신. 조작 불가.
- **자유롭게 놀기**: 아날로그 바늘을 자유롭게 드래그. 디지털 시계가 실시간으로 따라 바뀌어 "동기화"를 체감. 정답 개념 없음.
- **문제 풀기**: 랜덤 목표 시각을 디지털로 제시("오후 3시 47분을 만들어보세요") → 아이가 아날로그 바늘 조작 → 확인 버튼 → 정답/오답 판정.

## 상태 모델
```js
{ hour: 1-12, minute: 0-59, isPM: boolean }
```
모드별로 이 상태를 "시스템 시각이 채움"(실시간) / "드래그가 채움"(자유) / "퀴즈 정답 비교 대상"(문제 풀기)으로 다르게 사용한다.

## 아날로그 시계 렌더링
SVG `<line>` + CSS `transform: rotate()`.
- 분침 각도 = `분 × 6°`
- 시침 각도 = `(시 % 12) × 30° + 분 × 0.5°` (시침이 숫자 사이 위치에 자연스럽게 걸침)

## 드래그 로직
- **분침 드래그**: 포인터 각도를 계산해 가장 가까운 1분 단위로 스냅. 59분→0분으로 넘어가면 시가 자동 +1(또는 -1), 시침도 공식에 따라 자연스럽게 따라 움직인다. 12시 경계를 넘으면 오전/오후 자동 전환(11:59PM→12:00AM, 11:59AM→12:00PM).
- **시침 드래그**: 현재 분 값은 유지한 채 시 단위로만 스냅.
- 마우스와 터치 모두 Pointer Events(`pointerdown`/`pointermove`/`pointerup`)로 처리.

## 퀴즈 로직
- 목표: 시 1-12, 분 0-59, 오전/오후 랜덤 생성.
- 카드에 "오후 3시 47분을 만들어보세요" 형태로 목표 제시.
- 매 문제 시작 시 아날로그 시계는 목표와 다른 위치(예: 12:00 또는 랜덤)에서 시작.
- 확인 버튼 클릭 시 현재 `{hour, minute, isPM}`과 목표 비교.
  - 정답: 칭찬 애니메이션(이펙트) + 사운드, 잠시 후 다음 문제로 자동 전환.
  - 오답: "다시 확인해볼까요?" 안내 + 흔들림 애니메이션 + 사운드, 같은 문제 유지(재시도).

## PWA
- `manifest.json`으로 홈 화면 설치 지원.
- `sw.js`로 앱 셸 캐싱해 오프라인에서도 열림 (다른 지도 PWA들과 동일 패턴).

## 예외 처리
- 12시 경계 오전/오후 전환 정확성
- 마우스/터치 포인터 모두 대응 (PC, 태블릿)
- 오프라인 지원 (Service Worker)

## 테스트 계획
브라우저(Playwright)로 수동 검증:
- 모드 전환(실시간 ↔ 연습하기, 자유 ↔ 문제 풀기)
- 드래그 시 시/분 스냅 정확성과 시침-분침 연동
- 12시/오전오후 경계 케이스
- 퀴즈 정답 판정(경계 시각 포함)
- PWA 설치 가능 여부
- 모바일/태블릿 폭 레이아웃
