# 시계 친구 (clock-buddy)

아이에게 시간 읽는 법을 가르치기 위한 아날로그·디지털 시계 동기화 학습 웹앱(PWA)입니다.

**데모: https://spica07.github.io/clock-buddy/**

## 기능

- **실시간 보기**: 아날로그 시계(시침·분침·초침)와 디지털 시계가 실제 시각을 그대로 함께 보여줍니다.
- **연습하기 - 자유롭게 놀기**: 아날로그 바늘을 마우스/터치로 자유롭게 드래그하면 디지털 시계가 실시간으로 따라 바뀌어 두 시계의 관계를 체감할 수 있습니다. 분침이 59분에서 0분으로 넘어가면 시침도 자동으로 넘어가고, 12시 경계에서는 오전/오후도 자동 전환됩니다.
- **연습하기 - 문제 풀기**: "오후 3시 47분을 만들어보세요" 같은 문제를 랜덤으로 제시하면, 아이가 아날로그 바늘을 조작해 맞추고 확인 버튼을 누릅니다. 정답이면 애니메이션과 효과음으로 칭찬하고, 오답이면 다시 시도하도록 안내합니다.
- 시계판에 1분 단위 눈금과 5분 단위 숫자 가이드(5, 10, 15, ..., 60)를 함께 표시해 분 읽기 학습을 돕습니다.
- 오프라인에서도 열리도록 PWA로 설치할 수 있습니다.

## 기술 스택

빌드 도구 없이 순수 HTML/CSS/JavaScript로만 만들었습니다. 아날로그 시계는 SVG로 그리고, 바늘 드래그는 Pointer Events로 처리합니다.

```
clock-buddy/
├── index.html
├── manifest.json      # PWA 매니페스트
├── sw.js              # 오프라인 캐싱용 서비스워커
├── assets/
│   ├── css/style.css
│   └── js/
│       ├── clock.js    # 아날로그 시계 렌더링 + 드래그 로직
│       ├── quiz.js      # 퀴즈 출제/채점/효과음
│       └── app.js       # 모드 전환, 상태 관리
└── icons/
```

## 로컬에서 실행하기

```
py -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000` 접속.

## 배포

`main` 브랜치 루트에서 GitHub Pages로 자동 배포됩니다. `main`에 push하면 반영됩니다.
